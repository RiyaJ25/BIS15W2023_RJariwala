##Course Summary
#This course introduces the fundamentals of data science with an emphasis on data frequently used by biologists. We will use the R software environment to develop and practice key skills including data management, transformation, analysis, and visualization. Practical examples will span a range of disciplines including social science, ecology, evolution, and genetics. Labs will use a problem-solving approach that builds on previously learned skills culminating in a small, group-based project presented at the end of the quarter.
